##  Prompt 设计
1. 任务描述
2. 最终目标
3. 技术栈
4. 风格和视觉方向

6. 交互功能

为外卖移动应用「Foodiez」打造现代化、响应式落地页

## 目标
创建一个高转化的营销落地页，用于推广该应用、直观传递产品价值，并引导用户下载应用。

## 技术栈
采用：
- React + TypeScript
- Tailwind CSS
- Framer Motion（用于动画效果）
- 基于组件的架构
- 移动优先的响应式布局
- 符合无障碍标准的语义化 HTML

交付成果必须达到生产环境可用标准。

## 风格与视觉方向
- 简洁、现代、高端的用户界面
- 明亮、能勾起食欲的外卖风格
- 主色调：橙色（#FF6B35）
- 中性色：白色、浅灰色背景
- 柔和阴影、超大圆角（2xl）
- 流畅的微交互效果
- 使用高质量美食图片占位
- 字体：加粗、友好、高可读性
- 布局宽松、视觉层次清晰

## 页面结构

### 1）导航栏
- Logo：Foodiez
- 导航链接：使用流程、合作餐厅、用户评价、下载应用
- 滚动时固定在顶部
- 行动按钮：「获取应用」

### 2）首屏区域
左侧：
- 主标题：「你爱吃的美食，极速送达」
- 阐述核心价值的说明文字
- App Store + Google Play 下载按钮
- 信任标识（评分、配送时长、合作餐厅数量）

右侧：
- 展示应用界面的 iPhone 样机
- 浮动动画美食卡片或配送状态元素

### 3）用户口碑区
- 合作餐厅 Logo 横向排列
- 简短评价卡片（含头像、姓名、评价内容）
- 星级评分

### 4）使用流程（三步式）
每一步包含：
- 图标或插画
- 标题
- 简短说明

流程：
浏览餐厅 → 一键下单 → 极速配送

### 5）核心功能亮点
双列交替布局（图片 + 文字）：

功能：
- 订单实时追踪
- 个性化美食推荐
- 极速结账体验
- 独家本地特色餐厅

加入滚动触发的淡入动画。

### 6）应用预览区
- 横向可滑动手机样机
- 每个界面展示一项核心能力

### 7）促销横幅
- 「首单免配送费」
- 视觉突出、醒目
- 行动按钮

### 8）底部行动区
- 大号加粗标题
- 「下载 Foodiez，更快吃到美食」
- 应用商店下载按钮
- 渐变/彩色背景

### 9）页脚
- Logo
- 导航链接
- 社交媒体图标
- 应用下载按钮
- 版权信息

## 动画与交互
- 平滑滚动
- 元素进入视口时淡入/滑入
- 按钮、卡片的悬停效果
- 首屏视差/浮动元素
- 按钮点击微交互

## 响应式要求
- 全面适配移动端、平板、桌面端
- 小屏设备自动垂直堆叠
- 保持良好间距与可读性

## 无障碍要求
- 正确的标题层级
- 图片添加替代文本
- 清晰的焦点状态
- 符合 WCAG 色彩对比度标准

## 交付内容
需返回：
- 结构清晰的 React 组件
- 可复用用户界面区块
- Tailwind 样式代码
- Framer Motion 动画实现
- 不使用无意义占位文本，全部采用真实的外卖产品营销文案
