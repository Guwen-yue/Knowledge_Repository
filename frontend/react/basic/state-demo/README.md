## 异步
setCount 是异步调度更新，不会立刻修改 count。调用后当前作用域 count 仍是旧值，日志打印旧数据；等**本轮**代码执行完毕，组件重渲染才拿到新 count。
组件里的状态比较多，xyz 坐标 ，移动 多个状态同时改
react 状态的更新是靠react 组件函数的重新运行来实现。
三次调用count + 1 0 +1 本轮处理 三次都一样 ，合并， 只执行最后一次
如果非要达到+3的效果呢？ 多次执行，每一次都拿到最新的状态值
传函数，基于当前状态，返回全新状态，不在是闭包引用
