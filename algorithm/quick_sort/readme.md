## 快排 O(nlogn)
- pivot 基准值 一轮后顺序是确定的
- 比他小的放左边
- 比他大的放右边
双指针交换，
 

- 递归 对左边和右边的数组分别在做


快排（quick sort） 是一种基于分治策略的排序算法，运行高效（O(nlogn)）(平均情况),应用场景广泛
分而治之

## 递归 ，分治的区别
递归是代码实现方式（函数自身调用）
自顶向下缩小问题的规模
分治是算法思想，绝大多数用递归实现
分 + 治 + 合 三步
分 把大问题切成相互独立的小问题
治 解决小问题
合 合并小问题的结果

左边pivot右边

相等元素相对位置颠倒,完美体现快排不稳定
