### 数组的创建

- ADT 的认识
    连续的存储空间 + 特定的操作
- push pop shift unshift
  - 修改原数组 破坏了原数组，这些方法都不是纯函数 
   - push 返回的是新数组的长度
   - pop 移除的最后一个元素的值
   - shift 移除的第一个元素的值
   - unshift 添加的第一个元素的值
- 纯函数
  - 不修改原数组 
   - slice 返回的是新数组
   - concat 返回的是新数组

- new Array(7)
  指定长度的空数组
  [empty x 7]
  empty表示数组的这个位置还没被赋值
  不属于任何类型
  arr[0] = undefined
- (new Array(7)).fill(1)
创建一个长度确定，同时每一个元素也确定的值的数组
eg :  dp动态规划

## 遍历数组
- for 计数循环
  机器化，命令式，缺点是可读性不好
  优点性能最好
- for of 循环
  语义化好
- forEach 方法
  入调用栈 执行上下文
  优点是功能强大
  缺点是不能中途break 
- map 方法 (every some)
  基于forEach
  返回一个新数组 纯函数 
  filter筛选 函数结果为true留下
  every 检查数组是否所有元素都符合指定的条件
  some 检查数组是否至少有一个元素符合指定的条件
- filter 方法
- reduce 方法
